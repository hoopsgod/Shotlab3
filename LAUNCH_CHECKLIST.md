# Launch Checklist

Use this checklist before submitting ShotLab for review or announcing launch readiness.

## Registered Player Flows

- [ ] Registered player login succeeds.
- [ ] Registered player shot logging succeeds.
- [ ] Player leaderboard loads and displays expected data.

## Coach Flows

- [ ] Coach login succeeds.
- [ ] Coach dashboard visibility is correct for assigned players or teams.
- [ ] Coach leaderboard loads and displays expected data.

## Demo Player Flows

- [ ] Demo player login succeeds.
- [ ] Demo player shot logging succeeds.
- [ ] Demo player logout resets demo-only shots.

## Demo Coach Flows

- [ ] Demo coach login succeeds.

## Device And Review Quality

- [ ] Mobile Safari/iPhone test passes for core player, coach, and demo flows.
- [ ] No visible debug/sync/error boxes appear in normal successful flows.
