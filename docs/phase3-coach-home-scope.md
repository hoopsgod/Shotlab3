# Phase 3 — Coach Home scope lock

Phase 3 on this branch is limited to the Coach Dashboard / Coach Home vertical slice.

In scope:
- existing cinematic team identity hero and custom team branding;
- truthful Program Pulse using weekly makes against the Coach weekly makes goal;
- Athlete Attention;
- Recent Activity;
- Upcoming Event;
- existing primary Coach decision/action behavior;
- responsive Coach Home behavior and state resilience.

Out of scope:
- Coach Players and athlete profiles;
- Coach Events redesign;
- Leaderboards;
- Training / Drills;
- Strength & Conditioning;
- Player Home / Progress;
- schema, auth, permission, or persistence contract changes;
- Phase 4.

This branch must not be merged until exact-head build, runtime, Demo/registered parity, responsive, accessibility, performance-budget, and visual evidence gates pass.
