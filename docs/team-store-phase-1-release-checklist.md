# Team Store Phase 1 release checklist

- [x] Provider-neutral coach connection flow
- [x] Player/family store access
- [x] HTTPS-only external store URLs
- [x] Affiliate disclosure
- [x] Team branding authorization notice
- [x] Privacy-limited click analytics
- [x] No checkout, payment, inventory, tax, shipping, or returns handling
- [x] Contract tests
- [x] Production build gate
- [x] Post-merge Cloudflare production probe

A release is complete only when the `Team Store Production Smoke` workflow verifies the live production bundle.
