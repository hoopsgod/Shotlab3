# Phase 3 Coach Home acceptance evidence

The Phase 3 Coach Home candidate is not complete merely because source tests pass. Certification requires evidence on the exact final SHA for:

- Coach Demo and registered Coach parity;
- real, sparse, empty, loading, and error states;
- custom, missing, and unusual team logos;
- long team/player names and team-color variations;
- 320, 375, 390, 430, 768, 1024, 1280, 1440, and 1728+ responsive widths;
- zero unintended horizontal overflow;
- keyboard/focus and accessible-name checks;
- contrast and reduced-motion checks;
- production build and performance-budget checks;
- visual inspection of the Coach Home hierarchy.

The candidate must remain Coach Home only. Evidence from other routes is regression evidence, not permission to redesign those routes.
